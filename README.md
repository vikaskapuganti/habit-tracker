# Habit Tracker

A free habit tracker. Tick your habits every day, build streaks, and watch your whole year fill up with green squares, like a GitHub contribution graph.

**Live demo:** https://vikaskapuganti.github.io/habit-tracker/

## Features

- Add habits like Gym, Read 10 pages or Drink 3L water, each with its own colour
- Tick today’s habits with one tap
- Fix the last 7 days if you forgot to tick (tap any day)
- Current streak and best streak for every habit
- Today’s progress and your completion rate for the last 7 days
- A year view of green squares for all habits together, or one habit at a time
- Edit or delete habits
- Saved on your device, with no login or sign-up
- Works on any phone, with light and dark mode

## How the streaks work

- **Current streak:** the number of days in a row the habit was ticked, ending today. If you haven’t ticked it yet today, the count starts from yesterday, so your streak isn’t lost until the day is over.
- **Best streak:** the longest run of consecutive ticked days ever.
- **Last 7 days %:** ticked days ÷ possible days across all habits, counting only days after each habit was created.
- **Year view:** each square is a day. The darker the green, the bigger the share of habits completed that day.

## Built with

HTML, CSS and JavaScript. No frameworks and no libraries. Data is stored with the browser’s localStorage.

## Run it yourself

Download the files and open `index.html` in any browser.
